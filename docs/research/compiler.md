## Current Matching Toolchain

The current matching compiler for resident game code is the PlayStation 2
Metrowerks compiler distributed with CodeWarrior PS2 R3.01.

The command-line driver identifies itself as:

`Version 3.0.1`

The accompanying compiler backend identifies internally as:

`2.4.5 PlayStation 2 Compiler, build 0051`

Objects generated by this toolchain contain the ELF `.comment` string:

`MW MIPS C Compiler (2.4.1.01)`

That same `.comment` string is present in the retail executable, but testing
showed that it is not sufficiently specific to identify the exact backend:
multiple Metrowerks PS2 compiler revisions emit the same string.

The first exact source match, `SetAnalogStick__FPfPUcii`, was produced with:

`-O3,p -str=readonly -g`

together with the project's GCC-compatibility/no-system-path wrapper options.

The proprietary compiler is not redistributed by this repository. Local
builds expect it beneath `tools/mwcc/r301/`, or at a path supplied through
the `MWCC_R301` environment variable.
